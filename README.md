# Seq2Seq Transformer

A PyTorch-based **Encoder-Decoder Transformer** implementation for sequence-to-sequence learning. The project focuses on understanding and implementing the core architecture introduced in **"Attention Is All You Need"**, including multi-head attention, positional encoding, encoder-decoder cross-attention, masking, teacher forcing, and autoregressive generation.

---

## Overview

The Transformer is an encoder-decoder architecture designed to transform an input sequence into an output sequence without relying on recurrent networks such as RNNs, LSTMs, or GRUs.

This project implements the complete Seq2Seq pipeline:

```text
Input Sequence
      │
      ▼
  Tokenization
      │
      ▼
Token Embeddings
      │
      ▼
Positional Encoding
      │
      ▼
┌─────────────────┐
│     Encoder     │
│                 │
│ Self-Attention  │
│ Feed Forward    │
│ Add & Norm      │
└────────┬────────┘
         │
         │ Encoder Representations
         ▼
┌─────────────────┐
│     Decoder     │
│                 │
│ Masked Self-Attn│
│ Cross-Attention │
│ Feed Forward    │
│ Add & Norm      │
└────────┬────────┘
         │
         ▼
  Linear Projection
         │
         ▼
   Output Tokens
```

The implementation is designed primarily for **learning and understanding the Transformer architecture**, while still maintaining a clean and modular project structure.

## Transformer Architecture

The model follows the standard encoder-decoder Transformer design.

### Encoder

The encoder receives the source sequence and produces contextual representations.

Each encoder layer contains:

```text
Input
  │
  ▼
Multi-Head Self-Attention
  │
  ▼
Add & LayerNorm
  │
  ▼
Feed-Forward Network
  │
  ▼
Add & LayerNorm
```

### Decoder

The decoder generates the target sequence one token at a time.

Each decoder layer contains:

```text
Target Input
     │
     ▼
Masked Self-Attention
     │
     ▼
Add & LayerNorm
     │
     ▼
Cross-Attention
     │
     ▼
Add & LayerNorm
     │
     ▼
Feed-Forward Network
     │
     ▼
Add & LayerNorm
```

The cross-attention layer allows the decoder to attend to representations generated by the encoder.

---

## Attention

The project implements scaled dot-product attention:

```text
Attention(Q, K, V) =
softmax(QKᵀ / √dₖ)V
```

Multi-head attention divides the representation into multiple attention heads, allowing the model to learn different relationships within the sequence.

The decoder uses two different attention mechanisms:

* **Masked self-attention** — prevents the decoder from seeing future target tokens.
* **Cross-attention** — allows the decoder to attend to the encoder output.

---

## Masking

Two important masks are used.

### Padding Mask

Prevents the model from attending to `<PAD>` tokens.

```text
<PAD> tokens → ignored by attention
```

### Causal Mask

Prevents the decoder from accessing future tokens during training.

For example:

```text
Token 1 → can see Token 1
Token 2 → can see Token 1, 2
Token 3 → can see Token 1, 2, 3
```

This ensures that training matches the autoregressive generation process.

---

## Training

The decoder uses **teacher forcing** during training.

Given:

```text
Target:
<SOS> I love AI <EOS>
```

The decoder receives:

```text
<SOS> I love AI
```

and learns to predict:

```text
I love AI <EOS>
```

This creates a one-token-shifted prediction task.

The model is trained using cross-entropy loss while ignoring padded target tokens.

---

## Inference

During inference, the target sequence is not available.

Generation therefore happens autoregressively:

```text
Source Sequence
      │
      ▼
    Encoder
      │
      ▼
    <SOS>
      │
      ▼
    Decoder
      │
      ▼
Next Token
      │
      ▼
Append Token
      │
      ▼
Repeat
      │
      ▼
    <EOS>
```

The initial implementation uses **greedy decoding**, selecting the highest-probability token at every generation step.

## Installation

Clone the repository and create a virtual environment:

```bash
git clone <repository-url>
cd seq2seq-transformer-project
```

Create and activate the environment:

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### Linux/macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Dataset

Place the original dataset inside:

```text
data/raw/
```

After preprocessing, processed data should be stored in:

```text
data/processed/
```

The project expects a **parallel source-target dataset**, where each source sequence corresponds to a target sequence.

Example:

```text
Source:  Hello
Target:  Bonjour

Source:  How are you?
Target:  Comment allez-vous ?
```

The exact dataset can be adapted depending on the selected Seq2Seq task, such as:

* Machine translation
* Text transformation
* Summarization
* Question generation
* Other sequence-to-sequence tasks

---

## Configuration

Model and training parameters are controlled through:

```text
configs/config.yaml
```

Typical parameters include:

```yaml
model:
  d_model: 512
  num_heads: 8
  num_encoder_layers: 6
  num_decoder_layers: 6
  d_ff: 2048
  dropout: 0.1

training:
  batch_size: 32
  learning_rate: 0.0001
  epochs: 10

data:
  max_seq_length: 128
```

Values can be adjusted depending on dataset size and available hardware.
